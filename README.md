# Hi, I'm Linda Lim 👋

PhD researcher in transportation engineering, working at the intersection of
**traffic flow modeling, control theory, and data-driven methods** for safer and
more efficient mobility systems — including autonomous vehicles and freeway
operations.

I like turning messy real-world transportation data into models that are both
**physically consistent** and **predictive**, combining classical traffic theory
(cell transmission models) with modern data-driven tools (Koopman operator / DMD,
model predictive control).

---

## 🔬 Research interests
- Traffic flow modeling & simulation (Cell Transmission Model, network dynamics)
- Data-driven dynamical systems: Koopman operator theory, Dynamic Mode Decomposition (DMD)
- Model Predictive Control (MPC) for freeway / ramp management
- Autonomous vehicle safety and collision analysis
- Spatial / equity-oriented analysis of transportation data

## 🛠️ Skills & tools
- **Languages:** Python, MATLAB
- **Data & ML:** pandas, NumPy, scikit-learn, Jupyter
- **Modeling & control:** Koopman/DMD, Model Predictive Control, Cell Transmission Model
- **Geospatial & viz:** GeoPandas, kepler.gl, folium, Matplotlib
- **Workflow:** Git/GitHub, reproducible notebooks

## 📌 Featured projects
- **[LinkstoNetworksKMD-CTM](https://github.com/lindalim478/LinkstoNetworksKMD-CTM)** —
  Hankel-DMD / Koopman traffic-speed forecasting on a road network, with a Cell
  Transmission Model correction step to keep predictions physically consistent.
- **[CA_DMV_CollisionsPaper](https://github.com/lindalim478/CA_DMV_CollisionsPaper)** —
  Analysis of California DMV autonomous-vehicle collision and disengagement
  reports, joined with census demographics for spatial and equity analysis.
- **Koopman + MPC for freeway control** *(in progress)* — combining Koopman-based
  system identification with model predictive control for freeway traffic
  management.
